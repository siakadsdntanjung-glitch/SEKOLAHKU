    Pengaturan Surat Keterangan Lulus

    Siswa berstatus Lulus akan melihat tombol unduh surat setelah mencari datanya. Nama sekolah dan kepala sekolah diambil dari Pengaturan & Sambutan.

    Kode dipakai sebagai judul kolom nilai di Excel, mis. nilai_mtk. Setelah mengubah daftar mapel, unduh template baru.

    Unggah / tempel data siswa untuk fitur Cari Data Siswa. Baris pertama harus berisi judul kolom: nama, ibu, nisn, nis, kelas, status (opsional untuk surat lulus: jk, ortu, tempat, tgl_lahir, tahun_lulus, nosurat, nilai_(kode mapel); tanggal lahir lengkap, atau pisah menjadi kolom tanggal, bulan, tahun_lahir) (pemisah koma, titik koma, atau tab; kolom kelas & status boleh kosong). Setiap siswa wajib punya NISN atau NIS. Siswa dengan NISN/NIS yang sama akan diperbarui, bukan digandakan. Anda bisa langsung memakai template Excel di bawah.

    Spanduk Pengumuman Penting

    Tampil di paling atas website, mis. "PPDB dibuka" atau "Libur karena cuaca". Pengunjung bisa menutupnya.

    Cadangan Data Website

    Mengunduh satu file JSON berisi pengaturan, berita, guru, dokumentasi, foto latar, pendaftar, kotak saran, dan data siswa. File ini memuat data pribadi: simpan dengan aman.

    Gunakan link langsung ke gambar (berakhiran .jpg / .png) atau link Google Drive yang dibagikan ke "Siapa saja yang memiliki link". Link Google Photos tidak bisa dipakai.

    Boleh tempel link biasa atau link pendek dari Google Maps (Bagikan > Salin link), atau kode iframe dari Sematkan peta. Jika dikosongkan, peta dibuat otomatis dari alamat sekolah.

    Data di sini tampil untuk umum. Jangan isi NIP, nomor HP, atau alamat pribadi.
